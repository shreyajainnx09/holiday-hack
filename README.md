# Holiday Hack

**Live demo:** https://shreyajainnx09.github.io/holiday-hack/

## Description
A vacation-planning tool that looks up a country's public holidays for a given year and highlights "long weekend" opportunities — helping users stretch a handful of leave days into the longest possible breaks.

## Features
- Country + year selection to pull public holiday data
- Summary stats: total holidays, holidays remaining this year, and number of long-break opportunities
- Holidays list view and calendar view
- "Plans" feature to save chosen breaks
- Inspiration section for trip ideas
- Share functionality for a saved plan

## Tech Stack (typical — adjust to match your actual repo)
- HTML5 / CSS3 / JavaScript
- A public holidays API (e.g. Nager.Date or similar) for holiday data by country/year
- Client-side state for saved plans

## Getting Started
```bash
git clone https://github.com/shreyajainnx09/holiday-hack.git
cd holiday-hack
python3 -m http.server 8000
```
Visit `http://localhost:8000`.

## Usage
1. Select your country and year.
2. Review total/remaining holidays and detected long-break opportunities.
3. Browse the calendar or holidays list.
4. Save promising long weekends to "Plans" and share your itinerary.
